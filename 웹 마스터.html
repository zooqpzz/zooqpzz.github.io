웹 프론트엔드 마스터하기

HTML, CSS, JS의 핵심 개념을 눈으로 보고 체험하세요.

1. 제목과 문단 (Headings)

글의 제목과 본문을 정의합니다.

<h2>이것은 큰 제목</h2>
<p>일반적인 텍스트 문단입니다.</p>

이것은 큰 제목

일반적인 텍스트 문단입니다.

2. 링크 (Links)

다른 페이지로 이동합니다.

<a href="https://google.com" target="_blank">
  구글로 이동하기
</a>
구글로 이동하기 (새 창)

3. 이미지 (Images)

그림이나 사진을 삽입합니다.

<img src="고양이.jpg" width="150">

4. 목록 (Lists)

순서가 없는 목록(ul)을 만듭니다.

<ul>
  <li>사과</li>
  <li>바나나</li>
</ul>
  • 사과
  • 바나나

5. 표 (Tables)

데이터를 행과 열로 정리합니다.

<table border="1">
  <tr><td>이름</td><td>나이</td></tr>
  <tr><td>홍길동</td><td>20</td></tr>
</table>
이름나이
홍길동20

6. 입력 폼 (Forms)

사용자로부터 글자를 입력받습니다.

<input type="text">
<button>제출</button>

1. 글자 꾸미기 (Typography)

.text-style { color: red; font-weight: bold; }
그냥 글자입니다.

2. 배경과 여백 (Background & Padding)

.bg-style { background: blue; padding: 20px; }
밋밋한 박스

3. 테두리 (Border)

.border-style { border: 4px dashed purple; }
테두리 없는 박스

4. 그림자 효과 (Box Shadow)

.shadow-style { box-shadow: 5px 5px 15px gray; }
그림자 없는 박스

5. 가로 정렬 (Flexbox)

.flex-style { 
  display: flex; 
  justify-content: space-between; 
}
A (왼쪽)
B (오른쪽)

6. 마우스 오버 (Hover)

.hover-btn:hover { transform: scale(1.2); }

1. 클릭 카운터 (Event Listener)

let count = 0;
btn.addEventListener('click', () => { count++; });

숫자: 0

2. 텍스트 변경 (DOM 조작)

text.textContent = "반갑습니다!";

안녕하세요!

3. 스타일 토글 (다크모드)

box.style.backgroundColor = "black";

배경색을 바꿔보세요

4. 입력값 경고창 (Input Alert)

let name = input.value; alert(name);

5. 요소 추가 (createElement)

ul.appendChild( document.createElement('li') );
  • 기본 할 일

6. 시계 (setInterval)

setInterval( () => { ... }, 1000 );

현재 시간: 클릭하여 시작
